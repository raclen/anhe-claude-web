# 网络与隐私

一句话：**你的代码和对话不会经过本项目的任何服务器——本项目没有服务器。**

## 数据流向

```
你的浏览器  ←HTTP/SSE，仅本机→  本项目的 Node 服务  ←stdio→  你本机装的 claude CLI  →  你配置的上游
```

- 前端静态资源由本机的 Node 服务提供，没有 CDN、没有外链字体、没有分析脚本、没有遥测。
- 会话内容只在本机的两个地方落地：Claude Code 自己写的 `~/.claude/projects/*/*.jsonl`，
  以及本项目的元数据目录 `~/.anhe-claude-web`（只存标题、项目记录、UI 偏好，**不存对话正文**）。
- 模型请求由 `claude` 子进程直接发往**你自己在 `~/.claude/settings.json` 里配置的上游**。
  本项目不代理、不缓存、不中转这些流量，也无法读取你的密钥——它只是把子进程的
  stdin/stdout 接上，并且从不打印环境变量。

## 本项目主动发起的网络请求

只有两类，且都只在你触发时：

| 时机 | 目标 | 内容 |
|---|---|---|
| 你打开设置页 | 无 | — |
| 首屏检查上游健康 | 你配置的 `ANTHROPIC_BASE_URL` | 一次最小探针，用来判断「能不能用」，不发对话内容 |
| 你点「检查更新」 | `registry.npmjs.org` | 查最新版本号，不发任何标识 |

第一项如果你不需要，可以在设置里关掉（关掉后首屏不显示上游状态，出错时仍会提示）。

## 绑定地址

默认 `127.0.0.1`，局域网内其他机器连不上。**没有认证、没有 CSRF token、没有速率限制**，
因为它假设唯一客户端是同机的浏览器。

要做远程访问，用 SSH 端口转发，别开 `--host 0.0.0.0`：

```sh
ssh -NL 5419:127.0.0.1:5419 you@your-box
```

## 日志

- 不输出 token、API key、`Authorization` 头。
- 上游错误原文脱敏后再进日志。
- SSE 事件流里不发环境变量快照。
- 调试日志默认关闭；打开时也只写本机 stderr。

## 设备标识

不生成任何设备指纹、不持久化任何用于跨会话追踪的 id。`:memory:` 都不留。
